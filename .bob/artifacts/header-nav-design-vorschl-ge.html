Header & Navigation — Design-Vorschläge

3 Konzepte · Bob-Banner zentriert · Slide-in Nav · Desktop + Mobile

Option A
Bob-Banner full-width oben · Sidebar permanent links
Das Bob-Bild füllt eine breite Hero-Leiste über die volle Breite. Darunter teilt sich die Seite: permanente Navigations-Sidebar links, Content rechts. Auf Mobile kollabiert die Sidebar in einen Hamburger-Drawer.

Option B Empfohlen
Sticky Topbar + Hamburger · Bob-Banner darunter · Slide-in Drawer überall
Ein schlanker, sticky Topbar mit Hamburger-Button, Titel und Sprachschalter. Darunter ein kompakter Bob-Banner mit dem Standing-Bild (quadratisch, passt perfekt). Die Navigation öffnet sich immer als Slide-in Drawer — auf Desktop und Mobile identisch. Kein Layout-Umbau beim Toggle.

📱 Mobile: Topbar und Banner bleiben sichtbar. Drawer schiebt sich als Overlay von links — gleiche Interaktion wie Desktop. Kein separates Mobile-Layout nötig.

  • Nav nicht permanent sichtbar
Option C
Schmale Icon-Rail links (hover/klick expandierbar) · Bob-Banner als Page-Hero
Nur eine 50px breite Icon-Leiste links — beim Hover oder Klick expandiert sie zu einer Sidebar mit Labels. Bob-Banner erscheint innerhalb des Page-Contents. Maximal aufgeräumt, sehr viel Platz für den Inhalt.

📱 Mobile: Icon-Rail verschwindet komplett. Nur Hamburger-Button im Topbar. Drawer öffnet sich von links. Bob-Banner bleibt als Hero im Content-Bereich.

✓ Vorteile

  • Maximum Content-Platz
  • Sehr professionell, aufgeräumt
  • Bob-Banner als Seitenidentität

  • Mehr CSS/JS-Aufwand (Expand-Logik)
  • Icons ohne Labels können verwirren
  • Bob-Banner wiederholt sich auf jeder Seite

Empfehlung: Option B — Das Standing-Bob-Bild passt ideal in den kompakten Banner-Streifen, die Drawer-Navigation funktioniert auf Desktop und Mobile identisch, und der Implementierungsaufwand bleibt überschaubar. Das Landscape-Banner-Bild (ibm-bob.webp) entfällt als Header-Hintergrund; stattdessen wird es im About-Bereich oder als decoratives Element verwendet.
